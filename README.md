# Shepard Tone Builder

MIDI-генератор для Logic Pro: бесконечно растущий тон Шепарда и бесконечное ускорение ритма (ритм Риссе) любой длины. Темп проекта не меняется: все положения нот считаются в долях такта, поэтому результат одинаков при любом bpm и любом размере.

Плагин выдаёт MIDI-регион, который перетаскивается на дорожку с любым инструментом. Звук берётся из вашей библиотеки.

## Режимы

Тональный: шкала Шепарда дискретными шагами. Колокол громкости по высоте задаётся velocity (или CC11 при выводе по октавам). Артикуляция staccato или legato, наборы высот (хроматика, целотонная, октатоника, пентатоники, мажор, минор, дорийский, миксолидийский), направление вверх или вниз, шаг, диапазон, разброс голосов внутри шага, вывод в одну дорожку, по регистрам или по октавам.

Ритмический: ритм Риссе. Копии одного ритма идут со скоростями, кратными двум, громкость плавно переходит от медленных копий к быстрым. Метод «Плавный» (логарифмическая шкала времени) или «Ступенчатый» (ступени 1, 5/4, 3/2, 7/4, 2 на целых полиритмических сетках). Ускорение или замедление, число слоёв, сетка паттерна и пресеты.

Любая длина: длина региона в тактах и число циклов в нём независимы, цикл замыкается без шва.

## Сборка

- Ядро (C++17, без JUCE): `cmake -S . -B build_core -DSTB_BUILD_PLUGIN=OFF && cmake --build build_core && build_core/stb_tests`
- CLI: `build_core/shepard_cli tonal out.mid bars=8 cycles=2` и `build_core/shepard_cli tempo out.mid method=stepped stages=4`
- Плагин (AU, VST3, приложение) собирается в GitHub Actions на macOS, результат: `.pkg` и `.dmg`.

Исследование и формулы: проект «Плагины для работы», документ `claude/shepard-plugin-research.md`.


## 0.3.0

Тональный режим, изменения после проб в Logic:
- Питчбенд для легато теперь поднимается пилой на всю длину пробега и сбрасывается на переходе вниз, как делалось вручную. Прежний бенд на каждую ноту убран.
- Новая раскладка «Глиссандо» и профиль «Синтезатор, глиссандо»: одна длинная нота на голос и пробег, высоту ведёт питчбенд (диапазон бенда в синтезаторе 24), громкость CC11. Число голосов равно диапазону бенда, делённому на 6.
- Разброс времени и velocity (как Humanize в Transform), сдвиг голосов на k/N шага, мягкие края колокола в октавах, наклон громкости по регистру в дБ на октаву.
- Ритмический режим не менялся.

## 0.2.1

Питчбенд между нотами для легато-голосов (параметры в «Дополнительно»: питчбенд, диапазон бенда в полутонах, ширина глайда). Бенд пишется на каждую дорожку голоса отдельно и сдвигает высоту так, чтобы звучащая высота шла непрерывно через границу нот. Диапазон по умолчанию полтона, как у BBCSO Core. Вкладка «Темповой» переименована в «Ритмический», алгоритм не менялся.

## 0.2.0

Тональный режим переделан под живые библиотеки. Профиль «Струнные легато» пишет по одному треку на голос (линия легато вверх или вниз), а колокол громкости идёт непрерывной кривой CC1 (колесо модуляции) с CC11, который закрывает голос на краях диапазона. Скорость задаётся шагом (1/4 ... 1/64), длина региона подгоняется до целых циклов. Интерфейс сокращён до основных параметров, остальное под «Дополнительно». Логотип Teilor Music в шапке.

Команда CLI для голосов: `shepard_cli tonal out.mid layout=voices control=cc1 low=48 high=96 step=480 art=legato vmin=20 vmax=115 threshold=0 bars=12`
