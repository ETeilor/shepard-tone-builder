# Shepard Tone Builder

MIDI-генератор для Logic Pro: бесконечно растущий тон Шепарда и бесконечное ускорение ритма (ритм Риссе) любой длины. Темп проекта не меняется: все положения нот считаются в долях такта, поэтому результат одинаков при любом bpm и любом размере.

Плагин выдаёт MIDI-регион, который перетаскивается на дорожку с любым инструментом. Звук берётся из вашей библиотеки.

## Режимы

Тональный: шкала Шепарда дискретными шагами. Колокол громкости по высоте задаётся velocity (или CC11 при выводе по октавам). Артикуляция staccato или legato, наборы высот (хроматика, целотонная, октатоника, пентатоники, мажор, минор, дорийский, миксолидийский), направление вверх или вниз, шаг, диапазон, разброс голосов внутри шага, вывод в одну дорожку, по регистрам или по октавам.

Темповой: ритм Риссе. Копии одного ритма идут со скоростями, кратными двум, громкость плавно переходит от медленных копий к быстрым. Метод «Плавный» (логарифмическая шкала времени) или «Ступенчатый» (ступени 1, 5/4, 3/2, 7/4, 2 на целых полиритмических сетках). Ускорение или замедление, число слоёв, сетка паттерна и пресеты.

Любая длина: длина региона в тактах и число циклов в нём независимы, цикл замыкается без шва.

## Сборка

- Ядро (C++17, без JUCE): `cmake -S . -B build_core -DSTB_BUILD_PLUGIN=OFF && cmake --build build_core && build_core/stb_tests`
- CLI: `build_core/shepard_cli tonal out.mid bars=8 cycles=2` и `build_core/shepard_cli tempo out.mid method=stepped stages=4`
- Плагин (AU, VST3, приложение) собирается в GitHub Actions на macOS, результат: `.pkg` и `.dmg`.

Исследование и формулы: проект «Плагины для работы», документ `claude/shepard-plugin-research.md`.
